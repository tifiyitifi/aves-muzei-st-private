# Wallpaper family — rule register

One row per case the family has to get right. Coverage tokens are defined in
`docs/README.md`; `scripts/check-wallpaper-rules.ps1` resolves every `F:` token.
Native Kotlin tests have no host resolution and are recorded as
`-:native <TestClass>`, like the grouped wallpaper register does.

## State and files

| ID | Case | Behaviour | Why | Coverage |
| --- | --- | --- | --- | --- |
| STA-1 | State round trip | WHEN state is written and read, THE SYSTEM SHALL keep slots, effects, gestures and target | the file is the contract with the renderer | `F:wallpaper_state_test#JSON round-trips slots, effects, gestures and target` |
| STA-2 | Version guard | WHEN the state version is missing or unknown, THE SYSTEM SHALL reject the file | a newer file must not be half-read | `F:wallpaper_state_test#missing/unknown version is rejected` |
| STA-3 | Invalid slots | WHEN a slot is duplicate or invalid, THE SYSTEM SHALL drop it | a bad slot would draw or promote garbage | `F:wallpaper_state_test#invalid and duplicate slots are ignored` |
| STA-4 | Unknown names | WHEN a gesture or target name is unknown, THE SYSTEM SHALL fall back to the default | an old name must not break the page | `F:wallpaper_state_test#unknown gesture/target names fall back to defaults` |
| STA-5 | Recent list | WHEN recent artworks are recorded, THE SYSTEM SHALL keep the newest without slot paths and cap the list | a path points at a file the next bake may replace | `F:wallpaper_state_test#recent keeps the newest artworks without their slot paths`; `F:wallpaper_state_test#recent is capped` |
| STA-6 | New-photo marker | WHEN the marker is missing, THE SYSTEM SHALL tolerate its absence | an older state must still open | `F:wallpaper_state_test#JSON round-trips the new-photo marker and tolerates its absence` |
| STA-7 | Generation match | WHEN a runtime names another generation, THE SYSTEM SHALL not treat it as current | a slot id is only valid in its generation | `F:wallpaper_state_test#matches only the same generation` |
| STA-8 | Atomic write | WHEN state is written, THE SYSTEM SHALL use the temp directory and leave no partial file | a crash mid-write must not destroy the wallpaper | `F:wallpaper_state_test#writes and reads state atomically`; `F:wallpaper_state_test#overwrites an existing state without leaving temp files`; `F:wallpaper_state_test#bad JSON falls back to null` |
| STA-9 | Runtime | WHEN the renderer writes its slot, THE SYSTEM SHALL read it back | the renderer promotes without Dart | `F:wallpaper_state_test#writes and reads runtime` |

## Baking, promotion and the controller

| ID | Case | Behaviour | Why | Coverage |
| --- | --- | --- | --- | --- |

| CTL-7 | Schedule gate | WHEN the wallpaper is not in use, THE SYSTEM SHALL not schedule auto-advance | replacing the wallpaper stops its bakes | `F:wallpaper_controller_test#auto-advance is only scheduled while the wallpaper is in use` |

| CTL-10 | Spare depth | WHEN the two-ahead option is on, THE SYSTEM SHALL bake two spares; off SHALL keep one; the setting SHALL default to on | the first two taps are instant | `F:wallpaper_controller_test#bakes a spare for each of the first two taps`; `F:wallpaper_controller_test#keeps a single spare when the option is off`; `F:wallpaper_controller_test#the app setting decides the depth and defaults to on` |

| CTL-14 | Random advance | WHEN advancing with random ordering, THE SYSTEM SHALL never repeat a queued artwork and SHALL remember what it promoted without slot paths | a repeat looks like a broken tap | `F:wallpaper_controller_test#advancing with a random ordering never repeats a queued artwork`; `F:wallpaper_controller_test#advancing remembers the artwork it promotes, without slot paths` |
| CTL-15 | Fallback | WHEN the queue is empty, THE SYSTEM SHALL fall back to the newest artwork whose original still exists, and SHALL show nothing when none does | history must not resurrect a deleted file | `F:wallpaper_controller_test#the fallback skips artworks whose original file is gone`; `F:wallpaper_controller_test#the fallback is empty when nothing survived` |
